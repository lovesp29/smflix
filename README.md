# SPFlix

Upload `index.html` to the root of a GitHub repository, then enable GitHub Pages:

1. Open repository Settings.
2. Select Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/ (root)`.
5. Save and wait for the public link.

The website is self-contained. Photos are embedded inside index.html. Internet access is needed only for YouTube and Google Maps.
